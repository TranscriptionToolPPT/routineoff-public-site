Download questions

Can I use the tool without an account?+

No. The installer is public, but the application opens only with an active tool account issued by the administrator.

Are my documents uploaded to the server?+

No. Document content is processed locally on the Windows computer. The server handles account and session validation.

How will I receive updates?+

The installed application checks the official update channel and displays an in-app notice when a newer version is available.

Does this version work on macOS?+

No. Version 1.3.5 is a Windows release.
