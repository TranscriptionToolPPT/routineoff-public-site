Download questions

Can I try the tool before paying?+

Yes. Select Try Free for 4 Days in the installed app and verify your email. The trial lasts exactly 96 hours, needs internet access, and is available once per verified email and Windows device.

What happens when the trial ends?+

The app ends the trial session and opens the plans page. Subscribe to continue with a managed office account and tool users.

Are my documents uploaded to the server?+

No. Document content is processed locally on the Windows computer. The server handles account and session validation.

How will I receive updates?+

The installed application checks the official update channel and displays an in-app notice when a newer version is available.

Does this version work on macOS?+

No. Version 1.4.14 is a Windows release.
