Questions before you install

Does it work on macOS?+

The first commercial release is for Windows. A separate macOS edition requires a different document-counting and installation setup.

Does it require Microsoft Word?+

Microsoft Word is used for official Word-document counting and for the final count in supported OCR workflows. A supported Windows edition of Microsoft Office is required.

Are documents uploaded to the account server?+

No. Document content is processed locally by the desktop application. The account server handles sign-in, expiry, device identity, and session status.

Is every OCR result guaranteed?+

No OCR engine can guarantee perfect extraction from every scan. The tool retries difficult pages and marks uncertain or failed files for review rather than presenting them as reliable.

Does the tool need internet access?+

Internet access is required for account validation and session control. Document processing itself runs on the Windows computer.

Can two people share one tool user?+

A tool user is limited to one active device session. Office plans provide separate users for the number of employees included in the plan.
